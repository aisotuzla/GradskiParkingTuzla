# 🚗 TuzlaPark – Smart Parking & Navigation

TuzlaPark is a Progressive Web Application (PWA) that simplifies parking in Tuzla by combining interactive maps, GPS navigation, SMS parking payment, voice commands and offline support into a single mobile-first application.

---

## Features

### 🅿 Smart Parking

- Interactive parking map
- Parking Zone 0, 1 and 2 visualization
- Official parking prices
- SMS parking payment
- Parking timers
- Working hours detection

### 🗺 Navigation

- GPS positioning
- Route calculation
- Turn-by-turn navigation
- Closest parking finder
- Offline map fallback

### 🎤 Voice Assistant

- Voice commands
- Hands-free parking search
- Navigation control

### 📱 Progressive Web App

- Installable
- Offline capable
- Fast loading
- Mobile optimized
- Native App experience

### 🌍 Multi-language

- 🇧🇦 Bosnian
- 🇬🇧 English
- 🇩🇪 German
